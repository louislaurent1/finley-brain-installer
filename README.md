# finley-brain-installer

Installeur de Finley Brain, la mémoire de ton Finley, sur Mac.

Dans Ghostty :

```
curl -fsSL https://kryve.ai/emilie | sh
```

Le script vérifie ton Mac, te connecte à GitHub si besoin (une page s'ouvre dans ton navigateur), télécharge ta version privée de Finley Brain, puis lance l'installation guidée. Elle te demande tes deux clés, Voyage AI et OpenRouter. Aucune clé ne passe par ce dépôt.

Désinstaller (ta mémoire est gardée) :

```
curl -fsSL https://kryve.ai/emilie | sh -s -- --uninstall
```

Ce dépôt ne contient que ce script. Finley Brain lui-même est privé.
